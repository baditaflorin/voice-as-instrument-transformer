# Privacy

No analytics are enabled.

Microphone audio is processed in the browser for pitch tracking. The live instrument path does not upload microphone audio to a server.

Whisper transcription is optional and lazy-loaded. When used, the browser fetches model files from Hugging Face, then runs transcription locally in the browser. Captured phrase audio is kept in memory for the current page session and is not intentionally stored or uploaded by this app.

GitHub and PayPal links navigate to external sites with their own privacy policies.
