# Security Policy

## Supported Versions

Version `0.1.x` receives security fixes.

## Reporting a Vulnerability

Please report vulnerabilities by opening a private contact channel with the maintainer:

https://github.com/baditaflorin

Do not disclose exploitable details publicly before a fix is available.

## Secrets

This project is a static GitHub Pages app. It must not contain API keys, passwords, tokens, private keys, `.env` files with real values, or hidden frontend secrets.
