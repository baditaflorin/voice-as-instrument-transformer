# Code of Conduct

## Our Pledge

We pledge to make participation in this project a harassment-free experience for everyone.

## Standards

Examples of positive behavior include respectful feedback, patience with newcomers, and focusing criticism on code and ideas.

Unacceptable behavior includes harassment, insults, threats, sexualized attention, or publishing private information without permission.

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.
